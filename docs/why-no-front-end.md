# Views without an editing interface

The gallery records live in a database you own. Claude Code, Codex, OpenCode or Cursor can run the same commands. A change is a checked command, and a review is a read-only HTML document. npm run view renders the week, money and stock. npm run docs renders artist statements, condition records and exhibition checklists using brand.json.

This base has no phone app, camera upload, drag-and-drop hang planner, public website, online viewing room, payment processing or marketplace connection. A local database can run without a network once dependencies are installed, but agent services and hosted databases need their own connectivity. Static documents do not refresh themselves. A shared Postgres deployment needs access controls, backups and an operator before a team uses it. The free CLI uses a database account with write access and is not a multi-tenant application.

Those interfaces and connections are scoped custom work. The database remains yours whichever door you choose. Omni by Enterprise DNA can install, adapt and operate it for one setup fee followed by a retainer.
