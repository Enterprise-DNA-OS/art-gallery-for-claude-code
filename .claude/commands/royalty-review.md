description: Royalty review
---

Read royalties and `docs/compliance.md`. After an operator provides evidence, run `node scripts/gallery.mjs royalty-review "<sale ref>" --status=reported --evidence="<submission acknowledgement>" --json`. Use not-applicable only with a documented determination. Nothing is filed by this command.

Never send, publish, transfer funds or invent records. Drafts and documents remain private.
